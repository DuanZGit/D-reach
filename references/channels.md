# 通道速查：每个通道擅长什么、不擅长什么

选路时看这张表。规则（`pickByIntent`）命中已知场景会自动选；**没命中时先看这里，再用 `channels` 显式指定**。

## 一、免费通道（免 Key，不记账）

### `qianfan` 百度千帆 · 生成式综合答案
- **擅长**：中文「是什么 / 怎么样 / 有哪些」这类综述性问题。直接给一段成文答案，能当线索用。
- **不擅长**：**给的不是来源**，摘要可能编造或过时；英文问题弱；要精确数据（价格、日期、参数）不可靠。
- **代价**：免费。
- **别用它做**：需要可点击来源、需要精确数字、英文技术问题。

### `tf` TinyFish Search · 全网搜索
- **擅长**：什么都搜得到一点的万金油。$0/次，结果干净、去广告。英文强于中文。
- **不擅长**：中文本地生活（酒店/门店/活动）覆盖薄；每次只回 5 条左右，深挖要换通道。
- **代价**：$0 但计次（走 TinyFish 账户额度，当前余额 $12）。
- **别用它做**：需要 20 条以上候选、需要精确时效过滤。

### `fcdev` Firecrawl Developer Index · 编程一手源
- **擅长**：**官方文档、API 参数、GitHub README、issue**。7000 万+ 编程文档索引，查「某个 API 怎么调」「某个库的参数」最准。
- **不擅长**：非技术话题完全无用；中文文档覆盖少。
- **代价**：免费。
- **别用它做**：问旅行、问产品评测、问新闻。

### `se` StackExchange · 报错排障
- **擅长**：**报错信息、异常行为、配置冲突**。答案质量最高，通常带「为什么」和「怎么验证」。
- **不擅长**：只有技术话题；中文问题没有；问「怎么做某个功能」这种设计题弱。
- **代价**：免费。
- **别用它做**：非报错类的「怎么实现」、非技术问题。

### `hn` Hacker News · 深度技术讨论
- **擅长**：技术选型观点、行业趋势、某个工具的真实使用反馈（评论区常有踩坑经验）。
- **不擅长**：噪音大、时效短；非技术话题无用；中文零覆盖。
- **代价**：免费。
- **别用它做**：查具体 API、查报错、查中文内容。

### `jj` 掘金 · 中文技术长尾
- **擅长**：中文技术实战文章、踩坑记录、中文教程。
- **不擅长**：**只对技术问题有用**。实测拿「宜兴窑湖小镇 万圣节 烟花 门票」问它，返回「掘金签约季」「MarsCode 助力烟花绽放」—— 纯字面匹配，零相关信息。内容质量参差。
- **代价**：免费。
- **别用它做**：任何非技术的中文问题。

### `segfault` SegmentFault · 中文技术长尾
- **擅长**：中文技术问答，偏后端/运维。
- **不擅长**：同上，**只对技术有用**；内容比掘金更旧，很多答案停在 2020 年。
- **代价**：免费。
- **别用它做**：非技术问题、需要最新信息的技术问题。

### `oalex` OpenAlex · 学术元数据
- **擅长**：2.5 亿篇论文的**元数据**（标题、作者、引用数、DOI、摘要）。找某领域的代表作、看引用关系最准。
- **不擅长**：只给元数据和摘要，**不给全文**；中文论文覆盖少。
- **代价**：免费。
- **别用它做**：要读论文正文（用 `fcres`）、要中文资料。

### `crossref` Crossref · DOI 权威元数据
- **擅长**：DOI 校验、期刊/会议正式元数据、引用格式。和 `oalex` 互补，`crossref` 更权威但覆盖略窄。
- **不擅长**：同上，无全文。
- **代价**：免费。
- **别用它做**：找内容（它只确认「这篇存在」）。

## 二、限额通道（`--on` 点名会自动进 deep 档，会记账）

### `langsearch` · 时效 + 限域搜索
- **擅长**：**要最新信息**（新闻、发布、价格变动、政策）和**限定站点**的搜索。一次可回 20 条，是唯一能压数量的通道。
- **不擅长**：中文相关性一般（中文优先走 `qianfan`）；深度技术内容弱。
- **代价**：限额，本月已用 77 次。
- **别用它做**：中文综述性问题、深度技术排障。

### `exa` · 语义搜索
- **擅长**：英文语义搜索，问「有没有类似 X 的项目/文章」这类模糊需求。理解长句意图强于关键词匹配。
- **不擅长**：中文弱；结果偏博客/文章，官方文档不如 `fcdev`。
- **代价**：限额，本月已用 78 次。
- **别用它做**：中文问题、查具体 API 参数。

### `fcres` Firecrawl Research · 学术论文全文
- **擅长**：**论文正文**（`oalex` 只给摘要，要读全文用它）。论文端点不耗 credits。
- **不擅长**：只覆盖论文；非学术无用。
- **代价**：限额（论文端点除外）。
- **别用它做**：非学术问题。

### `bd` BrightData Google · 全网覆盖最广
- **擅长**：Google 结果，覆盖最广 —— 本地生活、电商、小众站点，其他通道搜不到的时候它是最后一张牌。
- **不擅长**：**慢**（单次常 5–15 秒）；**有硬限制** —— 知乎直接返回 `robots.txt` 拒绝，部分站要 KYC；间歇性 HTTP/2 断流（curl 退出码 92）。
- **代价**：**最贵的通道**，本月已用 39 次，连续失败 3 次会被自动跳过。
- **别用它做**：已知有其他通道能覆盖的场景（先在免费通道试）。

## 三、怎么组合

| 问题 | 组合 | 为什么 |
|---|---|---|
| 中文「是什么」 | `qianfan` | 摘要够用，不用搜 |
| 中文要来源 | `qianfan,tf` | 一个给线索一个给链接 |
| 英文技术选型 | `se,fcdev,hn` | 排障 + 文档 + 观点 |
| 查 API 参数 | `fcdev,qianfan` | 文档索引最准 |
| 报错 | `se,fcdev` | StackExchange 是终点 |
| 最新政策/价格 | `langsearch,tf` | 只有它能限时效 |
| 学术找论文 | `oalex,crossref` | 元数据免费且全 |
| 读论文正文 | `fcres` | 唯一给全文的 |
| 本地生活/酒店/门票 | `qianfan,tf` → 不够再 `bd` | 没有权威源，只能广撒 |
| 对比选型 | `tf,exa,qianfan` | 语义 + 全网 + 中文 |

## 四、规则没命中时怎么办

工具输出开头会写「**未命中已知场景**」，并列出通道菜单。这时：

1. 看问题本质属于上面哪一行，用 `channels` 指定；
2. 实在判断不了，`profile=base`（9 路免费全铺）比 `deep`（13 路含限额）划算；
3. 只有确认免费通道拿不到，才上 `bd`。
